# claude-code-plugins

Claude Code plugins and mods by ThePrimeLayer. Every plugin here is used day to day
before it is released, and each one lists the platforms it has been tested on.

## Install

In Claude Code (terminal, or the desktop app's Code tab):

```
/plugin marketplace add ThePrimeLayer/claude-code-plugins
/plugin install <plugin-name>@primelayer
```

Or from a shell:

```bash
claude plugin marketplace add ThePrimeLayer/claude-code-plugins
claude plugin install <plugin-name>@primelayer
```

Update later with `claude plugin marketplace update primelayer`.
